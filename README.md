# ことばの手がかり — 国語の練習

プリントを作るのではなく、画面で一題ずつ解く国語のアプリでやんす。くもわアプリに合わせた紫色の画面で、短い文章を5ステップで読み取るでやんす。

## 起動方法

Web版は [ことばの手がかり](https://penpeita.github.io/kokoro-reading/) でやんす。スマートフォン・タブレット・PCのブラウザで開けるでやんす。公開コードは [penpeita/kokoro-reading](https://github.com/penpeita/kokoro-reading) でやんす。

手元で使う場合は以下の手順でやんす。

1. ZIPを使う場合は、先にフォルダーへ展開するでやんす。
2. `index.html` をダブルクリックし、Edge・Chrome・Safariなどのブラウザで開くでやんす。
3. 登録・インストール・外部API・ネット接続は不要でやんす。出典のリンクを開く場合だけ通信するでやんす。

`index.html` 一つに画面・処理・全問題が入っているでやんす。ほかのファイルを移さなくても、このHTMLだけで練習できるでやんす。スマートフォンでは上のWeb版URLから開くのがおすすめでやんす。ローカルファイルで使う場合は、ファイルのプレビューではなくJavaScriptが動くブラウザで開く必要があるでやんす。

開発用にHTTPで表示したい場合は、Node.jsがあるPCで、このフォルダーをカレントディレクトリとして次を実行するでやんす。

```powershell
node serve.mjs
```

表示された `http://127.0.0.1:4173/` を開くでやんす。終了は `Ctrl+C` でやんす。この方法でも外部APIは使わず、このPCのループバックだけで配信するでやんす。ポートが使用中なら、既存サービスを止めず、HTMLを直接開く方法を使えるでやんす。

## 使い方

1. 「物語文」または「説明文」を選ぶでやんす。
2. レベル1〜4と、一度に読む文章数3・5・10題を選ぶでやんす。
3. 「練習をはじめる」を押すでやんす。同じ練習の中では文章が重複しないでやんす。
4. 各ステップで答えて進むでやんす。根拠を選ぶときは本文の行を押すと抜き出せるでやんす。行を選ぶと入力欄を選択行に置き換えるため、短く編集するなら行を選び終えてから行うでやんす。
5. 記述は解答例と見比べ、「説明できた」か「あとで見直したい」を選ぶでやんす。
6. 最後に自分の答え・解答例を振り返り、見直したい文章を再練習できるでやんす。

物語文は「出来事 → 言葉・行動 → 気持ち → 根拠 → 気持ちの変化」でやんす。レベル1は気持ちの複数選択と、変化前・変化後・手がかりの選択が中心でやんす。選択肢にない気持ちは自由に書けるでやんす。

説明文は「話題 → 筆者の考え → 根拠・理由 → 具体例 → 結論」でやんす。筆者の気持ちを当てる方式にはしていないでやんす。

画面を閉じる・再読み込みする・入口へ戻ると、途中の解答は残らないでやんす。氏名や成績の送信、アカウント、日ごとの回数制限は設けていないでやんす。

## 1000題の内訳と難しさ

| モード | レベル1 | レベル2 | レベル3 | レベル4 | 合計 |
|---|---:|---:|---:|---:|---:|
| 物語文 | 125 | 125 | 125 | 125 | 500 |
| 説明文 | 125 | 125 | 125 | 125 | 500 |
| 合計 | 250 | 250 | 250 | 250 | 1000 |

1000題は、**250の題材・場面をそれぞれ4段階にした1000の文章セット**でやんす。1題は本文と5つの設問で、合計5000ステップでやんす。「200文章×5問を1000題」と数えたものではないでやんす。ただし、1000種類の独立した筋の物語という意味でもないでやんす。同じ題材を、前の事情・行動の余韻・対比・文章の配置などを変えて読み深める構成でやんす。人物名だけを差し替えた問題はないでやんす。

- レベル1：短文。事実と気持ちを区別し、選択中心で練習するでやんす。
- レベル2：自分の言葉で短く書き、根拠を抜き出すでやんす。
- レベル3：行動・せりふからの推測や、理由と具体例の区別を練習するでやんす。
- レベル4：前の事情と後の言動、重なる気持ち、考えの条件・対比をつなぐでやんす。

小学4年生ごろから始め、四谷大塚の偏差値40〜44程度を目指す基礎〜標準の読み取りを想定しているでやんす。**四谷大塚の公式教材・認定教材ではなく、偏差値との対応を測定した問題集でもない**でやんす。本文は約64〜279字の短い練習で、本番の長文・語彙・漢字・時間配分の対策すべてを置き換えるものではないでやんす。レベル1〜2から始め、説明できるようになったら3〜4へ進む想定でやんす。

## 答え合わせの考え方

- 出来事などの選択問題は、教材に設定した答えと照合するでやんす。
- 抜き出しは、入力した言葉が本文にあるかを確かめるでやんす。空白・引用符・句読点・全角半角の一部をそろえて比較するでやんす。意味が根拠として適切かまでは機械判定しないでやんす。
- 自由記述や感情の選択には、正誤の自動判定をしないでやんす。解答例の単語と一致しない理由で不正解にしないでやんす。
- 気持ちと根拠を一緒に表示して、本文とつながるかを自分で振り返るでやんす。複数の気持ちや、変化後にも残る気持ちを認めるでやんす。
- 「説明できた」は本人の振り返りで、アプリが意味を正解と認定した表示ではないでやんす。迷う読みは、保護者や先生と文章を見ながら話せるでやんす。
- 結果の「最初に選べた事実の答え」は選択問題だけの記録でやんす。記述を含む総合得点や偏差値は出さないでやんす。

## 青空文庫の追加3題

通常のオリジナル1000題とは別に、入口から次の3題を選べるでやんす。

| 作品 | 練習する見方 |
|---|---|
| 新美南吉『ごん狐』 | 親切のつもりの行動と、その結果。後悔とつぐない。 |
| 新美南吉『手袋を買いに』 | 他人から聞いた見方と、自分の経験。母と子の視点の違い。 |
| 新美南吉『去年の木』 | 言葉にされない思い、約束、変わっても残る気持ち。 |

「受験で必ず出る」「読了が必須」として選んだ作品ではないでやんす。読む力の練習に使える場面として選び、前の場面の要約はアプリ作成と明示し、原文抜粋とは分けているでやんす。著者・底本・入力・校正・加工内容は `docs/SOURCES.md` に記録したでやんす。

## コードと検証

`index.html` の中で、CSS、`question-bank` のJSON、`classic-bank` のJSON、JavaScriptを確認できるでやんす。依存ライブラリやビルド作業なしで動くでやんす。対応するブラウザでは、現在の問題文などを読むだけのWebMCPツールも登録するでやんす。非対応でも学習機能は使えるでやんす。

Node.jsがある場合の検証コマンドは次の通りでやんす。

```powershell
node tests/verify.mjs
```

TypeScriptは使用していないため専用の型チェックはなく、JavaScript構文・全データの構造・状態遷移を検証するでやんす。検証結果と次回への引き継ぎは `docs/HANDOVER.md` に記録するでやんす。

## 編集について

問題の追加・修正はHTMLのJSON部分を編集してもよいでやんす。IDは一意にし、各文章の根拠と解説をセットで確認するでやんす。HTMLに直接埋め込むため、JSONの文字列中に`</script>`などのタグをそのまま入れず、`<`を `\u003c` にするでやんす。編集後は上記の検証とブラウザの操作確認を行うでやんす。
