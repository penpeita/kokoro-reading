# パスワード入場画面の追加

2026-09-24の変更でやんす。

案内された共通パスワードで入場する画面を追加したでやんす。全角数字を半角にそろえ、空欄・誤入力では入場できないでやんす。新規表示・再読み込みでは再入力を求め、パスワードや入場状態は保存しないでやんす。入場前のWebMCPはロック状態だけを返すでやんす。

変更ファイルは `index.html`、`README.md`、`tests/verify.mjs`、この記録でやんす。

環境変数 `ENTRY_TEST_PASSWORD` に案内された値を設定して `node tests/verify.mjs` を実行し、18検査グループが成功したでやんす。値を設定しない場合は正しいパスワードの検査だけスキップするでやんす。テストコードには実際のパスワードを書かないでやんす。

実ブラウザで誤入力、全角入力とEnterでの入場、再読み込みによる再ロックを確認したでやんす。Claude Codeの読み取りレビューを実施し、エラー処理の範囲、暗号処理の失敗時に入力欄を空にする処理、支援技術向けのエラー属性を改善したでやんす。修正後も18検査グループが成功したでやんす。

これは静的サイトの簡易的な入場制限でやんす。公開HTMLやリポジトリの内容を秘密にする仕組みではないでやんす。サーバー側の認証は実装していないでやんす。

次回はこの入場方式を維持し、変更後に入場と通常学習の両方を確認するでやんす。教材内容と1000題の内訳は変更していないでやんす。
