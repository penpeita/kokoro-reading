# 公開版の開発記録

2026-09-24に公開したでやんす。

## 公開先

- アプリ：https://penpeita.github.io/kokoro-reading/ でやんす。
- ソース：https://github.com/penpeita/kokoro-reading でやんす。
- GitHub Pagesは `main` ブランチのルートを配信するでやんす。`.nojekyll` で静的HTMLをそのまま配信するでやんす。

## 実装

オリジナル1000題は250題材を4段階に展開し、物語500題・説明500題でやんす。各題は5ステップで、青空文庫の追加3題は別枠でやんす。自由記述は意味の自動採点をせず、解答例と根拠を見比べて自己評価するでやんす。途中の答えは再読み込みや終了で消えるでやんす。

`index.html` に画面、問題データ、処理がまとまっているでやんす。`serve.mjs` は任意のローカル起動用で、`README.md` が使い方、`docs/SOURCES.md` が教材の出典でやんす。

## 検証

`node tests/verify.mjs` で16検査グループが成功したでやんす。1000題の件数、本文の重複、全題の抜き出し、複数解釈の受付、両モード全レベルの5ステップ遷移などを検証したでやんす。実ブラウザで物語文、説明文、名作の完了と結果表示を確認したでやんす。320px・390px幅で横はみ出しを確認し、修正済みでやんす。Claude Codeとの読み取りレビューを2回実施し、指摘を修正したでやんす。

公開後も実ブラウザで入口、物語レベル1の回答・解説、説明文レベル4の出題を確認したでやんす。配信成功の記録は [GitHub Actions](https://github.com/penpeita/kokoro-reading/actions/runs/35964026274) でやんす。

## 次回への引き継ぎ
