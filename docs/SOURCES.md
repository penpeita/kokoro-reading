## 青空文庫の取り扱い

新美南吉は1943年没で、日本で著作権保護期間が終了している作品を使ったでやんす。翻訳作品ではないでやんす。青空文庫の利用規準で、著作権の切れた作品の複製・再配布や注記形式の変更が認められていることを確認したでやんす。青空文庫や四谷大塚がこのアプリを監修・認定したという意味ではないでやんす。

- [青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)
- [青空文庫FAQ](https://www.aozora.gr.jp/guide/aozora_bunko_faq.html)

原文の漢字・仮名遣いは原則維持し、ルビタグの読みを表示から省いたでやんす。設問で参照できるよう、改行と段落を4つのまとまりに整理したでやんす。難しい語は画面の出典欄へ読み・説明を添えたでやんす。抜粋前の事情は独自要約であることを明示したでやんす。下の制作情報を保持するでやんす。
